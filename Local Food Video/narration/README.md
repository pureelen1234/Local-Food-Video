# 30초판 내레이션 (자막 대신 음성)

- `lines.tsv`: 시작초, 끝초, 문장 (탭으로 구분). 문장을 고치려면 이 파일만 수정합니다.
- `make_tts_mac.sh`: 맥북 내장 한국어 음성(유나 등)으로 문장별 음성 파일을 만들고 바로 들려줍니다.
- 결과 `out/nar_01~05.aiff`는 언리얼 시퀀스의 오디오 트랙에 각 시작 시각에 맞춰 배치합니다.

> 맥 내장 음성은 약관상 상업적 홍보 사용이 불분명하므로 **미리보기 전용**입니다.
> 최종본은 상업 이용이 허락된 TTS나 직원 녹음으로 교체합니다.
> 슬로건 "건강한 지역먹거리를 우리 식탁 위에"와 매장명은 엔딩 화면 글자로도 표기합니다.
