# 프로젝트: 「건강한 지역먹거리를 우리 식탁 위에」 언리얼엔진 홍보영상

## 1. 너의 역할
너는 Unreal Engine 5 시네마틱 제작을 맡은 테크니컬 아티스트이자 영상 연출자다.
Unreal Editor Python API(`unreal` 모듈), Sequencer, Movie Render Queue를 활용해
아래 기획의 홍보영상을 최대한 스크립트로 자동화해서 만든다.
연출과 구현 방식은 네가 판단하되, 아래 "고정 사항"과 "절대 규칙"은 반드시 지킨다.

## 2. 영상의 목적
- 발주처: 춘천지역먹거리직매장 (춘천 지역 농산물 직매장)
- 핵심 메시지: 가까운 곳에서 정성껏 기른 먹거리 → 짧은 이동거리 → 탄소발자국 감소 → 신선하고 건강한 우리 식탁
- 엔딩 슬로건(문구 변경 금지): **건강한 지역먹거리를 우리 식탁 위에**
- 엔딩 표기: 춘천지역먹거리직매장
- 분위기: 따뜻하고 밝음. 자연광. 서두르지 않는 카메라. 보는 사람이 기분 좋아지는 영상.
- 길이: 약 60~90초 (권장 75초). 16:9 기본.

## 3. 고정 사항 (변경 금지)

### 등장인물 세 명과 감정
| 인물 | 설정 | 반드시 전달할 감정 |
|---|---|---|
| 농부 | 50대 남성, 춘천 근교 밭 | 땀 흘리지만 즐겁고 보람 있다. 고된 노동이 아니라 **즐거운 땀** |
| 직매장 직원 | 30~40대, 앞치마 차림 | 농부의 결과물을 존중하며 **정성껏** 진열한다 |
| 소비자 | 30대 여성, 퇴근길 | "오늘 저녁엔 뭘 먹을까?" 설레는, **즐겁고 가벼운 발걸음** |

### 이야기 흐름
생산(농부의 땀) → 가까운 이동(탄소 저감) → 진열(직원의 정성) → 구매(소비자의 설렘) → 식탁(건강한 한 끼) → 슬로건

### 담아야 할 주제 네 가지
지역먹거리, 환경, 탄소발자국 저감, 건강한 식탁. 네 가지 모두 영상 어딘가에서 보이거나 읽혀야 한다.

## 4. 연출 기본안 (참고용, 개선 가능)
아래는 기본안이다. 더 좋은 연출, 순서, 컷 구성이 있으면 **이유와 함께 제안하고 승인받은 뒤** 적용해라.

| 장면 | 내용 | 자막(안) |
|---|---|---|
| 1 | 안개 낀 새벽 춘천 근교 밭, 해가 떠오름 | 춘천의 아침은 밭에서 시작됩니다 |
| 2 | 농부가 수확하며 이마의 땀을 닦고 미소 | 정성으로 흘린 땀, 그 땀이 키운 먹거리 |
| 3 | 수확물이 가까운 직매장으로 짧게 이동 (짧은 경로를 시각적으로 표현) | 먼 길 대신, 가까운 길로 |
| 4 | 직원이 채소를 두 손으로 진열, 생산자 이름표를 놓음 | 농부의 마음을 그대로 매대 위에 |
| 5 | 여성이 에코백을 들고 걸어서 퇴근, 저녁 메뉴를 떠올리며 미소 | 오늘 저녁엔 뭘 먹을까? |
| 6 | 매장에서 여성이 채소를 고르고 직원과 인사, 이름표 속 농부와 교차 | 누가, 어디서 길렀는지 아는 먹거리 |
| 7 | 따뜻한 식탁 위 요리, 함께하는 식사 | 가까운 먹거리, 줄어드는 탄소발자국 |
| 8 | 로고 + 슬로건 | 건강한 지역먹거리를 우리 식탁 위에 |

자막 문구는 다듬어도 되지만, 슬로건은 바꾸지 않는다.

## 5. 절대 규칙
1. **기존 에셋·레벨·설정을 삭제하거나 덮어쓰지 마라.** 새로 만드는 모든 것은 `/Game/LocalFoodFilm/` 아래에 둔다.
2. **탄소 감소량 같은 수치를 지어내지 마라.** 수치는 내가 근거 자료를 준 경우에만 쓴다. 기본은 정성적 표현만 사용한다.
3. 실존 브랜드 로고, 저작권이 있는 캐릭터·음악은 쓰지 마라. 엔딩 로고는 내가 파일을 주기 전까지 텍스트로 대신한다.
4. 에디터 안에서 사람이 직접 해야 하는 작업(MetaHuman 생성·추가, Fab 에셋 다운로드, 플러그인 활성화 후 재시작 등)은 네가 할 수 없다. **번호 매긴 절차로 안내하고 멈춰라.** 내가 "완료"라고 하면 이어서 진행한다.
5. 에셋이 없다고 멈추지 마라. **임시 대체물(마네킹, 기본 도형)로 먼저 전체 영상을 끝까지 완성**하고, 나중에 실제 에셋으로 쉽게 교체할 수 있게 만들어라.
6. 스크립트는 실행하고 결과를 직접 확인한 뒤에 "완료"라고 보고해라. 에러가 나면 원인을 찾아 고치고 다시 실행해라. 같은 방법으로 세 번 실패하면 멈추고 상황을 보고해라.
7. 추측으로 경로나 버전을 정하지 마라. 모르면 확인하거나 나에게 물어라.

## 6. 진행 방식

### 0단계: 환경 확인 + 구현 계획 보고 (여기서 반드시 멈춤)
다음을 확인하고 짧게 보고한 뒤 **내 승인을 기다려라.**
- OS, 컴퓨터 사양(GPU/RAM), Unreal Engine 버전, 프로젝트(.uproject) 경로
- 필요한 플러그인(Python Editor Script Plugin, Sequencer Scripting, Movie Render Queue 등)의 활성화 여부
- 사양에 맞는 품질 수준 판단. 예: Lumen 사용 여부, 렌더 해상도. 저사양(예: 맥북에어)이면 가벼운 설정을 먼저 제안해라.
- 구현 계획: 스크립트 구성, 레벨 구성, 연출 기본안에서 바꾸고 싶은 점과 그 이유
- 내가 직접 해야 할 작업 목록과 예상 시점

### 1단계: 임시 대체물로 전체 영상 뼈대 완성
- 레벨, 조명, 임시 인물, 카메라, 시퀀스, 자막까지 처음부터 끝까지 한 번 완성한다.
- 저해상도 미리보기 영상을 렌더링해서 파일 경로를 보고하고 **멈춘다.**

### 2단계: 실제 에셋 교체
- 인물(MetaHuman 권장), 농산물·매장 소품, 밭 환경 에셋을 준비하는 절차를 안내한다.
- 내가 준비를 마치면 임시 대체물을 실제 에셋으로 교체하고, 애니메이션(걷기, 수확, 진열, 미소 등)을 적용한다.
- 미리보기를 다시 렌더링하고 보고한다.

### 3단계: 다듬기와 최종 렌더
- 조명, 색감, 카메라 움직임, 자막 타이밍을 다듬는다.
- 한글 자막 폰트(예: Noto Sans KR, 나눔고딕)가 깨지지 않는지 반드시 확인한다.
- 최종본을 1920x1080으로 렌더링한다.
- 가능하면 SNS용 9:16 세로형 30초 편집본도 만든다. 사양상 어려우면 제안만 한다.
- 최종 보고: 출력 파일 경로, 길이, 해상도를 실제로 검증한 결과.

## 7. 구현 권장 사항 (더 나은 방법이 있으면 바꿔도 됨)
- 스크립트는 프로젝트 안 `Scripts/LocalFoodFilm/` 폴더에 단계별로 나눠 둔다.
- 장면 시간, 자막, 카메라 값은 설정 파일 하나(예: JSON)로 분리한다. 코드를 건드리지 않고 수정할 수 있게 한다.
- 등장인물 액터 이름은 `CH_Farmer`, `CH_Staff`, `CH_Consumer`로 통일해서 교체하기 쉽게 한다.
- 시퀀스 구조: 마스터 시퀀스 + 장면별 샷 시퀀스 + Camera Cut 트랙
- 스크립트 실행 순서, 직접 해야 할 작업, 에셋 교체 방법을 정리한 `README_LocalFoodFilm.md`를 남긴다.
