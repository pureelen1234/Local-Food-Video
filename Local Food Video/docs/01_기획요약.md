# 「건강한 지역먹거리를 우리 식탁 위에」 홍보영상 — 기획 요약

> 원본: [`00_기획서_원본.md`](./00_기획서_원본.md)

## 1. 개요
| 항목 | 내용 |
|---|---|
| 발주처 | 춘천지역먹거리직매장 |
| 제작 도구 | Unreal Engine 5 (Python API, Sequencer, Movie Render Queue) |
| 길이 / 비율 | 60~90초 (권장 75초) / 16:9, 최종 1920x1080 |
| 추가 편집본 | SNS용 9:16 세로 30초 (사양 가능 시) |
| 분위기 | 따뜻하고 밝음, 자연광, 느린 카메라 |
| 엔딩 슬로건 | **건강한 지역먹거리를 우리 식탁 위에** (문구 변경 금지) |
| 엔딩 표기 | 춘천지역먹거리직매장 (로고 파일 받기 전까지 텍스트) |

## 2. 핵심 메시지 흐름
생산(농부의 땀) → 가까운 이동(탄소 저감) → 진열(직원의 정성) → 구매(소비자의 설렘) → 식탁(건강한 한 끼) → 슬로건

필수 주제 4가지: **지역먹거리 · 환경 · 탄소발자국 저감 · 건강한 식탁**

## 3. 등장인물 (변경 금지)
| 액터 이름 | 인물 | 전달할 감정 |
|---|---|---|
| `CH_Farmer` | 50대 남성 농부, 춘천 근교 밭 | 즐거운 땀, 보람 |
| `CH_Staff` | 30~40대 직매장 직원, 앞치마 | 결과물 존중, 정성스러운 진열 |
| `CH_Consumer` | 30대 여성, 퇴근길 | 설렘, 가벼운 발걸음 |

## 4. 장면 구성 기본안 (75초 기준 시간 배분 예시)
| # | 시간(예시) | 장면 | 자막(안) |
|---|---|---|---|
| 1 | 0~8초 | 안개 낀 새벽 밭, 해돋이 | 춘천의 아침은 밭에서 시작됩니다 |
| 2 | 8~18초 | 농부 수확, 땀 닦고 미소 | 정성으로 흘린 땀, 그 땀이 키운 먹거리 |
| 3 | 18~26초 | 짧은 경로로 직매장 이동 | 먼 길 대신, 가까운 길로 |
| 4 | 26~35초 | 직원이 두 손으로 진열, 생산자 이름표 | 농부의 마음을 그대로 매대 위에 |
| 5 | 35~43초 | 에코백 든 여성 퇴근길, 미소 | 오늘 저녁엔 뭘 먹을까? |
| 6 | 43~54초 | 채소 고르기, 직원과 인사, 이름표 속 농부 교차 | 누가, 어디서 길렀는지 아는 먹거리 |
| 7 | 54~66초 | 따뜻한 식탁, 함께하는 식사 | 가까운 먹거리, 줄어드는 탄소발자국 |
| 8 | 66~75초 | 로고 + 슬로건 | 건강한 지역먹거리를 우리 식탁 위에 |

※ 시간 배분은 요약자가 붙인 예시이며 확정값이 아님. 연출 변경은 **이유 제시 → 승인 후** 적용.

## 5. 절대 규칙 요약
1. 기존 에셋·레벨·설정 삭제/덮어쓰기 금지 → 신규 에셋은 모두 `/Game/LocalFoodFilm/`
2. 탄소 감소량 등 **수치 창작 금지** (근거 자료 제공 시에만 사용)
3. 실존 브랜드 로고·저작권 캐릭터·음악 사용 금지
4. 사람이 해야 할 작업(MetaHuman, Fab 다운로드, 플러그인 활성화·재시작)은 번호 절차로 안내 후 대기
5. 에셋 부족 시 멈추지 말고 **임시 대체물로 끝까지 완성**, 교체 쉽게 구성
6. 스크립트는 실행·결과 확인 후 보고, 동일 방법 3회 실패 시 중단·보고
7. 경로·버전 추측 금지

## 6. 진행 단계
| 단계 | 내용 | 멈춤 지점 |
|---|---|---|
| 0 | 환경 확인(OS, GPU/RAM, UE 버전, .uproject 경로, 플러그인) + 구현 계획 보고 | **승인 대기** |
| 1 | 임시 대체물로 레벨·조명·인물·카메라·시퀀스·자막 전체 완성 → 저해상도 미리보기 렌더 | **보고 후 대기** |
| 2 | 실제 에셋(MetaHuman, 소품, 밭 환경) 교체 + 애니메이션 → 미리보기 재렌더 | 보고 |
| 3 | 조명·색감·카메라·자막 다듬기, 한글 폰트 확인, 1920x1080 최종 렌더, 9:16 30초본 | 최종 검증 보고 |
