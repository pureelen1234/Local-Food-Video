## 공식 사양 확인 (Epic 문서)
- UE 5.2부터 Apple Silicon 네이티브 지원
- Apple Silicon 권장 RAM: M1/M2 기준 16GB 이상, **최소 8GB**
- macOS는 하드웨어 레이트레이싱 미지원, Lumen은 소프트웨어 방식만 가능

→ 8GB는 **최소 사양 경계선**. 에디터 실행은 가능하나 MetaHuman 3명 + 밭/매장 환경 + 렌더는 멈춤·충돌 위험이 큼.
