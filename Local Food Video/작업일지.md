## 30초판 구성 (3번 장면 제외, 8번 장면은 7번에 통합)
| 장면 | 길이 | 내용 |
|---|---|---|
| 1 새벽 밭 | 3초 | 해돋이 |
| 2 농부 | 6초 | 수확 → 땀 닦고 미소 |
| 4 진열 | 5초 | 직원이 채소와 이름표를 놓음 |
| 5+6 퇴근·구매 | 7초 | 에코백 들고 걸어와 고르고 인사 |
| 7 식탁 + 마무리 | 9초 | 가족 식사 5초(자막: 가까운 먹거리, 줄어드는 탄소발자국) → 화면이 서서히 어두워지며 슬로건 「건강한 지역먹거리를 우리 식탁 위에」 + 「춘천지역먹거리직매장」 4초 |

- 필수 주제 4가지: 지역먹거리·건강한 식탁(슬로건), 탄소발자국 저감(식탁 자막), 환경(밭·에코백 화면)

### 30초판 컷 구성 (클로즈업 위주 · 토마토 한 알이 처음부터 끝까지 이어짐)
| 시간 | 컷 | 화면 |
|---|---|---|
| 0~3초 | 1 | 이슬 맺힌 빨간 **토마토** 초근접, 뒤로 해가 떠오르며 빛이 번짐 |
| 3~5초 | 2-1 | 농부 손이 그 **토마토**를 따는 손 클로즈업 |
| 5~7초 | 2-2 | 밀짚모자 아래 이마 땀방울 → 수건으로 닦음 (앞쪽에 토마토 바구니) |
| 7~9초 | 2-3 | **토마토**를 들고 활짝 웃는 농부 얼굴 클로즈업 |
| 9~11.5초 | 4-1 | 직원이 두 손으로 **토마토 상자**를 매대에 내려놓는 손 클로즈업 |
| 11.5~14초 | 4-2 | **토마토 상자** 위 생산자 이름표 클로즈업 (생산자명·춘천) |
| 14~17초 | 5 | **뒤에서 따라가는 카메라**로 가볍게 걷는 발걸음. 팔에 걸친 에코백이 걸음에 맞춰 살짝 흔들림 (자막: 오늘 저녁엔 뭘 먹을까?) |
| 17~20초 | 6 | 이름표 옆 **토마토**를 집는 손 → 직원과 눈인사 |
| 20~22초 | 7-1 | 김이 오르는 **토마토 달걀볶음** 클로즈업 |
| 22~25.5초 | 7-2 | 숟가락을 드는 가족 미소 클로즈업 |
| 25.5~30초 | 7-3 | 식탁 위 **토마토** 요리 클로즈업 → 서서히 어두워지며 슬로건·매장명 |

- 토마토 = 농부의 땀 → 직원의 정성 → 소비자의 설렘 → 가족의 식탁을 잇는 하나의 이야기
- 클로즈업은 배경을 적게 만들어도 되므로 맥북 8GB 부담도 줄어듦
